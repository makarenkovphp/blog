# My Blog

Простой блог с категориями и постами на чистом PHP (без фреймворков) с использованием MySQL и шаблонизатора Smarty.

## Технологический стек:

● PHP 8.1+

● База данных MySQL 8.0

● Шаблонизатор Smarty

## Структура данных:

● Категория:

○ Название

○ Описание

● Статья:

○ Изображение

○ Название

○ Описание

○ Текст

○ Категория (одна или несколько)

○ Кол-во просмотров

## Обязательные страницы:

● Главная страница:

○ Вывести каждую категорию, в которой есть статьи и отобразить 3 последних поста (по дате публикации).

○ Вывести кнопку “Все статьи” для каждой категории.

● Страница категории:

○ Вывести название, описание, список статей

○ Реализовать сортировку статей (по кол-во просмотров, по дате публикации)

○ Реализовать пагинацию

● Страница статьи:

○ Вывести всю информацию о статье

○ Вывести блок из 3 похожих статей

## Дополнительный функционал:

● Реализовать функционал для сидинга категорий и статей

## Установка:

### 1. Получение проекта

Клонируйте репозиторий и перейдите в каталог проекта:
```bash
git clone https://github.com/makarenkovphp/blog.git
```
```bash
cd blog
```
Если проект уже находится на компьютере, перейдите в его каталог.

### 2. Установка PHP-зависимостей

Установите зависимости Composer:
```bash
composer install
```
Убедитесь, что установлены PHP и расширение PDO MySQL:
```bash
php -v
```
```bash
php -m | grep -iE 'PDO|pdo_mysql'
```
Если расширение pdo_mysql отсутствует, установите его для используемой версии PHP.

### 3. Запуск MySQL в Docker

```bash
docker compose up -d mysql
```
Проверьте состояние контейнера:
```bash
docker compose ps
```
MySQL доступен с хостовой системы на порту 3307.

Внутри Docker-контейнера MySQL использует стандартный порт 3306.

### 4. Создание структуры базы данных

Для новой, ещё не инициализированной базы данных выполните:
```bash
docker compose exec -T mysql mysql -u blog -pblog blog < database/schema.sql
```
Эту команду нужно выполнять один раз при первоначальной настройке.

Повторный запуск может завершиться ошибкой, если таблицы уже существуют.

### 5. Заполнение тестовыми данными

Из корня проекта выполните:
```bash
php bin/seed.php
```
Скрипт заполнит базу тестовыми категориями и статьями.

### 6. Запуск сайта

Запустите встроенный PHP-сервер:
```bash
php -S localhost:8000 -t public
```
Откройте сайт в браузере:

http://localhost:8000

Остановить сервер можно сочетанием Ctrl+C.

### 7. Остановка Docker

Остановить контейнер MySQL, сохранив данные в Docker volume:
```bash
docker compose down
```
Запустить его снова:
```bash
docker compose up -d mysql
```
Данные базы хранятся в Docker volume mysql_data и сохраняются при обычной остановке контейнеров.

Остановить контейнер MySQL и удалить базу данных MySQL:
```bash
docker compose down -v
```

## Использование ИИ:

При разработке проекта использовался ИИ-ассистент в качестве вспомогательного инструмента для консультаций, анализа и написания кода, решения отдельных технических задач. Предложенные решения и сгенерированный код анализировались и проверялись в контексте проекта. Ответственность за итоговую реализацию и проверку работоспособности приложения остаётся за разработчиком.

Основные направления использования:

* **Планирование разработки:** помощь в декомпозиции требований задания на небольшие этапы и определении последовательности реализации.
* **Проектирование структуры:** обсуждение организации каталогов, разделения ответственности между контроллерами и репозиториями, а также взаимодействия PHP, MySQL и Smarty.
* **Работа с базой данных:** консультации по структуре таблиц, связям между статьями и категориями, SQL-запросам, сортировке и пагинации.
* **Оптимизация запросов:** анализ количества SQL-запросов на главной странице и поиск способов избежать проблемы N+1 при получении последних статей для категорий.
* **Отладка:** помощь в анализе ошибок PHP, подключении к базе данных и проверке работоспособности отдельных частей приложения.
* **Документация:** подготовка инструкций по установке зависимостей, запуску MySQL через Docker, заполнению базы тестовыми данными и запуску приложения локально.
